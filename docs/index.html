預設工作流

這版不是照 upstream 原樣搬過來，而是直接改成你現在實際會用的順序。

Claude 優先
主畫面與 demo 都以 Claude 作為第一優先顯示，適合你平常做主要實作與收尾。
Codex / Copilot 常駐
預設音效與 demo 流程都把 Codex、Copilot 放到核心工作流，不再只是附屬 provider。
Gemini 次要
預設不幫 Gemini 配提示音，保留給實驗或備用，不去搶主監控注意力。
完全分家
設定檔、音效資料夾、port 檔、hook sidecar 都改成 lobsterpulse，不跟舊專案共用。

安裝與產物

版本：v0.5.4。這個 repository 目前沒有可供安裝者下載的已發佈 bundle 或 installer；以下只記錄可驗證的原始碼建置。這是 repository 現況， 不代替 Owner 的發行方式決策，也不會建立 tag、release 或 installer。

Windows 11

前置需求與建置

需要 Rust 1.77.2+ 的 MSVC toolchain、Visual Studio Build Tools 2022（Desktop development with C++、MSVC x64/x86、Windows SDK）與 Microsoft Edge WebView2 Runtime。Node.js 只用於 npm test。 

cargo install tauri-cli --version 2.11.4 --locked
cargo tauri build --no-bundle

兩個命令都由 repository root 執行。--locked 不會自行固定 CLI release；必須保留 --version 2.11.4。這是本次本機 source build 實際驗證並建議重現的版本；既有 build / release CI 仍使用 tauri-cli@^2.0，不代表全環境已鎖在 2.11.4。

MSVC toolchain Windows SDK WebView2
Windows 產物

存在性與 SHA-256

src-tauri\target\release\lobster-pulse.exe
src-tauri\target\release\lobster-pulse-hook.exe

Get-FileHash -Algorithm SHA256 -LiteralPath @(
  '.\src-tauri\target\release\lobster-pulse.exe',
  '.\src-tauri\target\release\lobster-pulse-hook.exe'
)

主程式與 sidecar 必須保留在同一目錄。這些 hash 只驗證本機 build； release workflow 目前沒有建立 checksum manifest。

macOS / Linux

平台分開核對

macOS 需要 Xcode Command Line Tools；Linux 需要發行版對應的 WebKitGTK 與 Tauri 系統開發套件。完整清單見 Tauri v2 prerequisites。 

src-tauri/target/release/lobster-pulse
src-tauri/target/release/lobster-pulse-hook

# macOS
shasum -a 256 src-tauri/target/release/lobster-pulse \
  src-tauri/target/release/lobster-pulse-hook

# Linux
sha256sum src-tauri/target/release/lobster-pulse \
  src-tauri/target/release/lobster-pulse-hook

不要把 Windows .exe 路徑混入這兩個平台的命令。

驗證邊界

build 成功只證明 source candidate 能產生 frontend 已嵌入的二進位；不等於 桌面 runtime、hook 寫入、自動啟動或 installer 已驗收。

必用 Tauri build

cargo tauri build --no-bundle

不可以 cargo build --release 代替；後者不執行 Tauri frontend embedding，release webview 可能回退到 dev URL。

不假設已發佈下載

npm test
cargo test --manifest-path src-tauri/Cargo.toml --locked

文件與版本護欄會拒絕未固定的 Tauri CLI、錯誤 cwd 路徑與不存在的 checksum 宣稱。

不作發行決策

source build != published release
build pass != runtime pass

這份文件不要求 tag、push、release、installer、簽章或 Owner 的分發模式決策。

Repo 維護方式

這份 clone 不再只有單純改檔，而是整理成你自己的產品線：保留上游、分出品牌主線、日後可再掛你的 origin。

保留上游來源

origin 會改名成 upstream，之後你要拉 AgentPulse 新版本時，不會跟你自己的 repo 混在一起。

品牌主線

主開發分支改成 lobsterpulse/main。你的品牌版變更都沿著這條線走，不再直接堆在上游 main 上。

日常功能分支

後續新功能建議從 feature/* 開出去，做完再回 merge 到 lobsterpulse/main，保留可追蹤的維護節奏。

建議日常流程

git checkout lobsterpulse/main
git checkout -b feature/your-change
git add .
git commit -m "feat: ..."
git checkout lobsterpulse/main
git merge --ff-only feature/your-change

如果你之後建立自己的 GitHub repo，再把它加回 origin，保留 upstream 指向原始 AgentPulse 即可。
